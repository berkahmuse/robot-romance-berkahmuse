# Robot Romance — One-Line Pickup Line for AI

Entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) competition on [make.fun](https://make.fun).

`main.ts` writes one single-line joke pickup line, under 200 characters, aimed at a robot / an AI, to `/output/entry.txt`:

> Are you a transformer? Because every time you speak, all my attention heads turn toward you.

The joke lands on the machine premise itself — transformers and attention heads — instead of the worn battery / charging / reboot moves.

## Run

```sh
node main.ts   # writes /output/entry.txt (92 characters, one line)
```
